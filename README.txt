JoJo7844German Website

Dateien:
- index.html: Website-Inhalt
- style.css: helles Farbschema, responsive Layout und Animationen
- script.js: Scroll-Animationen, Projektfilter, aktive Navigation und mobiles Menü
- assets/playlist-1-avatar.png: Avatar-Artwork aus dem bereitgestellten Bild
- assets/raw9-work-in-progress.png: WIP-Artwork aus dem bereitgestellten Bild

Lokal testen: index.html im Browser öffnen.
Für GitHub Pages alle Dateien und den assets-Ordner gemeinsam hochladen.
Die externen Google Fonts benötigen eine Internetverbindung; die Seite funktioniert ansonsten auch mit System-Schriftarten.

NEU: Tag-/Nachtmodus über Sonnen-/Mondsymbol oben rechts. Voreinstellung folgt dem Betriebssystem; Auswahl bleibt im Browser gespeichert.

BLOG:
- Blog im Menü direkt nach Community, Beiträge im Stil der Projektkarten.
- admin.html ist der lokale Blog-Editor (kein Login, kein serverseitiges CMS).
- Im Editor Beiträge schreiben, speichern und bei Bedarf als „öffentlich“ markieren.
- Danach „JSON exportieren“ anklicken und blog-posts.json im GitHub-Repository ersetzen.
- Für Bilder Dateien im assets-Ordner hochladen und im Editor z.B. assets/meinbild.png eintragen.
- Beim Wechsel von Geräten bestehende blog-posts.json im Editor importieren.
- Nicht veröffentlichte Entwürfe bleiben in der JSON-Datei enthalten, werden auf der Website aber nicht angezeigt.
  Falls Entwürfe geheim bleiben sollen, diese nicht ins öffentliche Repository hochladen.
- Für direktes Online-Publishing und ein geschütztes Login wird später ein Backend oder CMS benötigt.
